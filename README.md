# Atividades de JavaScript

Resolução das quatro atividades do PDF **Slide10Javascript-Aluno-S(1)**.

## Conteúdo

1. **Exercício 1 — Soma de dois números:** lê dois inteiros com `prompt()`, converte com `parseInt()` e apresenta o resultado com `alert()`.
2. **Exercício 2 — Soma de vários números:** recolhe valores até o utilizador digitar `s`, guarda-os num array e calcula a soma.
3. **Exercício 3 — Manipulação do DOM:** botões alteram o título e a cor de fundo da página.
4. **Exercício 4 — Validação de login:** o formulário usa o evento `submit`, destaca campos vazios com borda vermelha e mostra uma mensagem por campo.

## Como abrir

1. Extraia o ficheiro ZIP.
2. Abra `index.html` num navegador (Chrome, Firefox, Edge, etc.).
3. Escolha a atividade desejada. Não é necessário instalar programas ou dependências.

## Estrutura

- `index.html`: menu principal.
- `exercicio1.html` a `exercicio4.html`: páginas das atividades.
- `css/style.css`: estilos partilhados.
- `js/exercicio1.js` a `js/exercicio4.js`: lógica JavaScript de cada atividade.

**Nota:** “Java” e “JavaScript” são linguagens diferentes. Como as atividades do PDF são explicitamente de JavaScript, o projeto foi feito em HTML, CSS e JavaScript.
